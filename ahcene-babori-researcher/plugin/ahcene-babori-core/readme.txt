Academic data layer (custom post types, taxonomies, fields, profile settings, SEO/schema, contact form, import framework) for the website of Dr. Ahcene Babori. Works with the ahcene-babori-academic theme and with Polylang (EN/FR/AR).

== Description ==
Publications, Books, Research Projects, Presentations, Academic Service, Teaching, Research Resources and Research Notes, with research-area, type, year and keyword taxonomies. Researcher identifiers, statistics, CV files and the portrait are managed in "Researcher" in the dashboard.
